# Transport CLI App

Transport CLI App — це консольний застосунок для розв’язання транспортної задачі з дискретним вибором потужностей, попиту та штрафами за перевиробництво або недопоставку.

Програма дозволяє створювати, завантажувати та зберігати індивідуальні задачі, розв’язувати їх жадібним і генетичним алгоритмами, порівнювати отримані результати та проводити експерименти з параметрами алгоритмів.

## Можливості

- введення задачі вручну;
- зчитування задачі з JSON-файлу;
- випадкова генерація задачі;
- балансування транспортної задачі;
- побудова плану перевезень методом Фогеля;
- розв’язання задачі жадібним алгоритмом;
- розв’язання задачі генетичним алгоритмом;
- порівняння результатів алгоритмів за значенням цільової функції;
- проведення експериментів з параметрами генетичного алгоритму;
- збереження задачі та розв’язків у JSON-файли;
- збереження результатів експериментів у CSV-файли;
- побудова та збереження графіків у PNG-файли.

## Вимоги

Потрібен Python версії **3.10 або новіше**.

Перевірити версію Python можна командою:

```bash
python --version
```

або:

```bash
python3 --version
```

Для побудови та збереження графіків використовується пакет `matplotlib`.

Встановити залежності можна командою:

```bash
pip install -r requirements.txt
```

## Завантаження з GitHub

Склонуйте репозиторій:

```bash
git clone <URL_РЕПОЗИТОРІЮ>
```

Перейдіть у папку проєкту:

```bash
cd Transport-CLI-App
```

Якщо назва папки у вас інша, перейдіть у фактичну папку, де знаходиться файл `main.py`.

Якщо репозиторій уже був скопійований раніше, оновіть його командою:

## Головне меню

Після запуску відкривається головне меню:

```text
1 - Введення даних задачі
2 - Розв'язати задачу всіма розробленими алгоритмами
3 - Провести експерименти
4 - Вивести дані задачі
5 - Вивести розв'язки задачі
6 - Зберегти поточну задачу у файл
7 - Зберегти розв'язки у файл
0 - Завершити роботу
```

## Введення задачі

У програмі доступні три способи задання задачі:

```text
1 - Ввести дані самостійно
2 - Зчитати з файлу
3 - Згенерувати випадково
0 - Повернутися в головне меню
```

Для швидкої перевірки можна використати приклад задачі:

```text
data/sample_problem.json
```

Якщо програма вже пропонує шлях за замовчуванням, достатньо просто натиснути `Enter`.

## Формат JSON задачі

Файл задачі має містити такі поля:

```json
{
  "A": [
    [100, 120, 150, 180],
    [180, 200, 230, 250],
    [150, 200, 250, 300]
  ],
  "D": [
    [80, 90, 100, 110],
    [100, 120, 150, 170],
    [100, 120, 140, 160],
    [80, 90, 110, 130]
  ],
  "C": [
    [5, 8, 4, 6],
    [3, 5, 7, 4],
    [6, 2, 5, 8]
  ],
  "over_penalty": [2, 3, 4],
  "under_penalty": [10, 12, 15, 10]
}
```

Опис полів:

```text
A — матриця можливих потужностей постачальників;
D — матриця можливих рівнів попиту споживачів;
C — матриця транспортних витрат;
over_penalty — штрафи за перевиробництво;
under_penalty — штрафи за недопоставку.
```

## Розв’язання задачі

Щоб розв’язати задачу:

1. запустіть програму;
2. оберіть пункт `1 - Введення даних задачі`;
3. введіть задачу вручну, зчитайте її з JSON-файлу або згенеруйте випадково;
4. поверніться в головне меню;
5. оберіть пункт `2 - Розв'язати задачу всіма розробленими алгоритмами`;
6. задайте параметри генетичного алгоритму;
7. перегляньте результати через пункт `5 - Вивести розв'язки задачі`.

Після запуску генетичного алгоритму програма також зберігає графік збіжності в папку `output/`.

Приклад файлу:

```text
output/ga_convergence.png
```

## Експерименти

У програмі передбачено режим експериментів для аналізу роботи алгоритмів.

Доступні експерименти:

```text
1 - Дослідити параметр умови завершення MaxStallGen
2 - Дослідити вплив ймовірності мутації
3 - Дослідити вплив розмірності задачі на час роботи
4 - Дослідити вплив розмірності задачі на точність
0 - Повернутися в головне меню
```

Результати експериментів виводяться в консоль у вигляді таблиць.

Крім цього, результати експериментів автоматично зберігаються у папку:

```text
output/
```

Для експериментів створюються:

- CSV-файли з табличними результатами;
- PNG-файли з графіками.

Приклади файлів:

```text
output/experiment_1_max_stall_<timestamp>.csv
output/experiment_1_max_stall_<timestamp>_cost.png
output/experiment_1_max_stall_<timestamp>_time.png
output/experiment_1_max_stall_<timestamp>_generations.png

output/experiment_2_mutation_<timestamp>.csv
output/experiment_2_mutation_<timestamp>_cost.png
output/experiment_2_mutation_<timestamp>_time.png

output/experiment_3_dimension_time_<timestamp>.csv
output/experiment_3_dimension_time_<timestamp>_plot.png

output/experiment_4_dimension_accuracy_<timestamp>.csv
output/experiment_4_dimension_accuracy_<timestamp>_cost.png
output/experiment_4_dimension_accuracy_<timestamp>_gap.png
output/experiment_4_dimension_accuracy_<timestamp>_win_rate.png
```

CSV-файли можна відкрити в Excel, Google Sheets або використати для побудови додаткових графіків.

## Збереження задачі та розв’язків

Поточну задачу можна зберегти через пункт меню:

```text
6 - Зберегти поточну задачу у файл
```

Розв’язки задачі можна зберегти через пункт меню:

```text
7 - Зберегти розв'язки у файл
```

Задачі та розв’язки зберігаються у форматі JSON.

Експерименти зберігаються окремо у форматах CSV та PNG у папку `output/`.

## Приклад типового сценарію роботи

```text
1. Запустити програму.
2. Обрати пункт 1.
3. Обрати спосіб введення задачі: вручну, з файлу або випадкова генерація.
4. Якщо задача зчитується з файлу, вказати шлях data/sample_problem.json.
5. Повернутися в головне меню.
6. Обрати пункт 2 для розв’язання задачі алгоритмами.
7. Задати параметри генетичного алгоритму.
8. Обрати пункт 5 для перегляду результатів.
9. За потреби обрати пункт 7 для збереження розв’язків у файл.
10. За потреби обрати пункт 3 для запуску експериментів.
```

## Можливі проблеми

### Програма не знаходить `data/sample_problem.json`

Перевірте, що запуск відбувається з папки, де знаходиться файл `main.py`.

Правильний приклад розташування:

```text
main.py
data/sample_problem.json
```

Якщо ви запускаєте програму з кореня репозиторію, вводьте шлях:

```text
data/sample_problem.json
```

Не потрібно вводити назву репозиторію перед `data`, якщо ви вже знаходитесь усередині папки проєкту.

### Команда `python` не працює

Спробуйте використати:

```bash
python3 main.py
```

або перевірте, чи Python доданий до змінної середовища `PATH`.

### Помилка `ModuleNotFoundError: No module named 'matplotlib'`

Встановіть залежності:

```bash
pip install -r requirements.txt
```
