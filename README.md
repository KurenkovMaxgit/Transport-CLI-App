# Transport CLI App

Transport CLI App — це консольний застосунок для розв’язання транспортної задачі з дискретним вибором потужностей, попиту та штрафами за перевиробництво або недопоставку.

Програма дозволяє створювати, завантажувати та зберігати індивідуальні задачі, розв’язувати їх жадібним і генетичним алгоритмами, порівнювати отримані результати та проводити експерименти з параметрами алгоритмів.

## Можливості

- введення задачі вручну;
- зчитування задачі з JSON-файлу;
- випадкова генерація задачі;
- балансування транспортної задачі;
- побудова плану перевезень методом Фогеля;
- розв’язання задачі жадібним алгоритмом;
- розв’язання задачі генетичним алгоритмом;
- порівняння результатів алгоритмів за значенням цільової функції;
- проведення експериментів з параметрами генетичного алгоритму;
- збереження задачі та розв’язків у JSON-файли.

## Вимоги

Потрібен Python версії **3.10 або новіше**.

Перевірити версію Python можна командою:

```bash
python --version
```

або:

```bash
python3 --version
```

Програма використовує тільки стандартну бібліотеку Python. Зовнішні пакети не потрібні.

## Головне меню

Після запуску відкривається головне меню:

```text
1 - Введення даних задачі
2 - Розв'язати задачу всіма розробленими алгоритмами
3 - Провести експерименти
4 - Вивести дані задачі
5 - Вивести розв'язки задачі
6 - Зберегти поточну задачу у файл
7 - Зберегти розв'язки у файл
0 - Завершити роботу
```

## Введення задачі

У програмі доступні три способи задання задачі:

```text
1 - Ввести дані самостійно
2 - Зчитати з файлу
3 - Згенерувати випадково
0 - Повернутися в головне меню
```

Для швидкої перевірки можна використати приклад задачі:

```text
data/sample_problem.json
```

## Формат JSON задачі

Файл задачі має містити такі поля:

```json
{
  "A": [
    [100, 120, 150, 180],
    [180, 200, 230, 250],
    [150, 200, 250, 300]
  ],
  "D": [
    [80, 90, 100, 110],
    [100, 120, 150, 170],
    [100, 120, 140, 160],
    [80, 90, 110, 130]
  ],
  "C": [
    [5, 8, 4, 6],
    [3, 5, 7, 4],
    [6, 2, 5, 8]
  ],
  "over_penalty": [2, 3, 4],
  "under_penalty": [10, 12, 15, 10]
}
```

Опис полів:

```text
A — матриця можливих потужностей постачальників;
D — матриця можливих рівнів попиту споживачів;
C — матриця транспортних витрат;
over_penalty — штрафи за перевиробництво;
under_penalty — штрафи за недопоставку.
```

## Розв’язання задачі

Щоб розв’язати задачу:

1. запустіть програму;
2. оберіть пункт `1 - Введення даних задачі`;
3. введіть задачу вручну, зчитайте її з JSON-файлу або згенеруйте випадково;
4. поверніться в головне меню;
5. оберіть пункт `2 - Розв'язати задачу всіма розробленими алгоритмами`;
6. перегляньте результати через пункт `5 - Вивести розв'язки задачі`.

## Експерименти

У програмі передбачено режим експериментів для аналізу роботи алгоритмів.

Доступні експерименти:

```text
1 - Дослідити параметр умови завершення MaxStallGen
2 - Дослідити вплив ймовірності мутації
3 - Дослідити вплив розмірності задачі на час роботи
4 - Дослідити вплив розмірності задачі на точність
0 - Повернутися в головне меню
```

Результати експериментів виводяться в консоль і можуть бути використані для подальшого аналізу.

## Збереження результатів

Поточну задачу можна зберегти через пункт меню:

```text
6 - Зберегти поточну задачу у файл
```

Розв’язки задачі можна зберегти через пункт меню:

```text
7 - Зберегти розв'язки у файл
```

Файли зберігаються у форматі JSON.

## Приклад типового сценарію роботи

```text
1. Запустити програму.
2. Обрати пункт 1.
3. Обрати спосіб введення задачі: вручну, з файлу або випадкова генерація.
4. Повернутися в головне меню.
5. Обрати пункт 2 для розв’язання задачі алгоритмами.
6. Обрати пункт 5 для перегляду результатів.
7. За потреби обрати пункт 7 для збереження розв’язків у файл.
```

## Можливі проблеми

Якщо програма не знаходить файл `data/sample_problem.json`, перевірте, що запуск відбувається з папки, де знаходиться файл `main.py`.

Якщо команда `python` не працює, спробуйте використати:

```bash
python3 main.py
```

або перевірте, чи Python доданий до змінної середовища `PATH`.
